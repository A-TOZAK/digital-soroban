# デジタルそろばん

ブラウザでさわれる、本物に近いそろばん。小学校3年・4年の算数「そろばん」の練習つき。

- 公開先（予定）：`https://a-tozak.github.io/digital-soroban/`
- リポジトリ（予定）：`A-TOZAK/digital-soroban`
- 手元で見る：`python3 -m http.server 8796` → http://localhost:8796
  （Claude Code からは `.claude/launch.json` の `soroban`）

## この教材の位置づけ

導入の道具ではない。そろばんの一時間目は実物をさわる時間。
**これは、実物をさわったあとに、家で何度でもやり直すための練習の道具。**
教科書の時数は3年が2時間、4年が1時間しかなく、そこでつまずいた子はもう一度さわる機会がない。その穴を埋める。

## 決めごと（変えるときはここを読む）

### 珠を動かす向き ＝ 大きい位から
`assets/abacus.js` の `DIGIT_ORDER = 'high-to-low'`。**ここ1か所でヒントの手順が全部入れかわる。**

下の位から足すと、まだ触っていない位が繰り上がりで勝手に変わり、子どもの頭の中と盤がずれる
（47＋38 を一の位から足すと、十の位が4から5になった状態で「十の位に3を足す」ことになる）。

⚠ **運指の順序を書いた一次資料は見つからなかった。** 学習指導要領・同解説・啓林館の年間指導計画／単元展開例／評価規準を
すべて当たって0件。「珠算界の作法は上位から」という前提も手元の資料では裏が取れていない。
外に出す文書でそこを根拠にするなら、全国珠算教育連盟か日本珠算連盟の一次資料を当たること。

くり上がりのときの中の順（上の位を先か、補数を先か）は `CARRY_ORDER = 'carry-first'`。

### 17けたの理由
実物のそろばんは13・17・21・23けたの規格。4年の「10兆＋20兆」は整数で14けた、
小数第二位まで取ると16けた要るので13けたでは足りない。次の規格が17けた。
**京は小学校で扱わないので、問題では作らない**（`data/courses.js` の `g4-big-read` で範囲を止めている）。

### 一の位のしるし
3年のタブでは動かせない（`sb.lockMarker(true)`）。位の考えが固まっていない時期に
「一の位はどこでもよい」と見せると盤そのものへの信頼が揺らぐため。4年のタブで解禁。
問題を解いているあいだは、学年にかかわらず固定（答え合わせの読みがぶれるため）。

### 3年の本線は整数だけ
万の単位と小数第一位は、**指導要領解説では3年の内容**だが、**教科書では4年で扱うことが多い**。
そのため3年の画面では「もっとやってみる」に分け、根拠の一文を添えている。

### ヒント
既定オフ。押したときだけ、次の**ひと手だけ**出す。光った所を押す作業にしないため。
「なぜそう動かすか」はコースの1問目だけ言葉で出す（2けたの回は毎回）。

### 見た目
そろばん本体だけ design-system のフラット原則の例外（教具の再現なので木目と立体感が要る）。
まわりのボタン・パネル・文字は辞典三兄弟と同じ土台（クレー体・藍1色・角丸3〜4px）。

## 検査

`tests/test.html` をブラウザで開く。24万通り以上をその場で回して、1件でも赤が出たら公開しない。

1. 珠の形から数を読む（総当たり＋位の名前つきの言いかた）
2. 運指の手順どおりに動かすと必ず答えになるか（0〜399 の加減を総当たり）
3. コースごとの型が混ざっていないか（1コース500問）
4. 学年の範囲を出ていないか（1コース300問。京が出ない・小数の位をこえない）

画面の側は、実機の Browser で mobile / tablet / desktop を目で見る。ビルドが通った≠合格。

## 絵について

野々宮すみれ（六人衆・水彩）が14枚。紙面の作りは**研究大会サイト**（`rika-kentaikai-2026`）にそろえている。

⭐**そろばんの全景を描いた絵は1枚もない。** 真下にコードで描いた写実の盤があるので、
水彩の盤と桁数・珠数が食い違うと壊れる。発注書の最上位に
「必ず端で切る・2〜4列しか見せない・数えられないこと」を置いてある。
絵を足すときも、この線は動かさないこと。

透過は `~/Desktop/LiFE with/17 素材集/scripts/melt_to_paper.py`。
**地が暗い2枚（`c_g3-man` 帳面・`c_g4-big` 星空）は溶かせない**ので、
そのままwebpにして CSS で角だけまるめている（`drill.js` の `SOLID_ART`）。

スマホ幅のスクショは `~/Claude/Tools/mobile-shot/shot.py` で焼く
（`chrome --headless --window-size=390` はmacOSでスマホ幅を再現しない）。
